## Featured Work

### MPC Threshold Signature Services

[Repository](https://github.com/Sandwichzzy/MPC-TSS)

Designed and developed enterprise MPC wallet threshold signing infrastructure using Go, `bnb-chain/tss-lib`, `libp2p`, and WebSocket.

### Multi-Chain Wallet Services

[Repository](https://github.com/Sandwichzzy/exchange-wallet-services)

Built wallet middleware for centralized exchange scenarios, covering deposit scanning, withdrawals, asset collection, hot/cold wallet transfers, offline signing, transaction broadcasting, status callbacks, and risk-control integration.

### Cross-Chain Staking Protocol

[Repository](https://github.com/Sandwichzzy/Crosschain-Staking-Contract)

Developed smart contracts for a cross-chain staking protocol based on Ethereum Beacon Chain staking, allowing Layer 2 users to stake assets and participate in Layer 1 validator operations.

### Cross-Chain Bridge

Pool-based cross-chain bridge system.

1. [Bridge Contracts](https://github.com/Sandwichzzy/Bridge-Contracts) - Smart contracts for cross-chain asset bridge logic.
2. [Relayer Node](https://github.com/Sandwichzzy/relayer-node) - Relayer service for cross-chain data synchronization.
3. [Gas Oracle](https://github.com/Sandwichzzy/gas-oracle) - gRPC gas oracle service for synchronizing EVM-chain gas fees.
